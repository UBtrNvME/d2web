# Layout limits

Generated by `mise run measure:layout` (spec 0008) on 2026-10-31: darwin/arm64, chromium 156.0.8078.4, wall time of a compile through the shipping client and worker (includes protocol overhead, excludes painting). One run, one machine: use the orders of magnitude, not the digits. Runs longer than 90 s are aborted by `budgets.maxLayoutMillis`. The wasm is single-threaded, so the page stays responsive but TALA's cost cannot be shared.

Size is shapes / connections as D2 counts them (`countObjects`). When a layout is slow, the consumer may request `layout: 'dagre'` or `'elk'` itself; they give different layouts from TALA and d2web never switches on its own.
