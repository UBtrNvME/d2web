# Plan: advertised fields, actions and interactions (spec 0017)

Status: accepted 4 November 2026 (ADR 0014, spec 0017, defaults taken). Task list: [todo-0017.md](todo-0017.md). Separate from `plan.md` (historical research) and `todo.md` (product ledger) by the user's choice.

## Overview
The d2editor inspector lists six hard-coded fields. Replace that with a description derived from D2: per selected object, its fields with value domains, its actions, and its gestures, rendered by the inspector, for shapes, containers, content elements and connections.

## Assumptions (spec §6 proposed defaults; change them and tasks 1, 4 and 6 move)
- Export route: a build-time JSON file shipped with d2editor, no protocol change.
- Fields D2 accepts but the painter does not draw are advertised with a "not drawn yet" note.

## Dependency graph
```
1 keyword export (Go build -> JSON) + test vs imports/d2
  └─ 2 capabilities() for shapes (TS, pure) + test vs real compile
       ├─ 3 inspector renders style fields, with reset   (first visible slice)
       │    ├─ 4 layout fields (top/left, width/height, near, grid, direction)
       │    └─ 6 unavailable fields show D2's reason (traits, engine, imports)
       └─ 5 connection description + inspector (arrowheads, direction, reverse)
7 interactions panel + keyboard move (needs traits only; after 2 for the shared description)
```

## Decisions
- `capabilities.ts` is pure (object, board, engine, table in; description out) so it is testable in Node without a browser, like `traits.ts`.
- The inspector keeps today's controls for label, fill, stroke, shape, icon and language during the move; each is replaced by the generic renderer only when its test passes, so no task leaves the editor broken.
- No change to `packages/d2web` or the worker protocol.

## Risks
| Risk | Impact | Mitigation |
| --- | --- | --- |
| D2 accepts a keyword the worker's `set` op refuses (or writes oddly) | High | Task 2's test sets every advertised field on a real compile; a refused field is marked unavailable, never advertised |
| `main.ts` is 603 lines; the inspector grows in it | Med | New code in `capabilities.ts` and `inspector.ts`; `main.ts` only wires |
| Chromium cannot launch in some sandboxes (see todo.md, 4 November) | Med | Node tests carry the logic; browser cases run outside the sandbox and the handoff says so |
| Keyword domains in D2 source are not all declarative (some validated in code) | Med | Task 1 lists which domains are read from tables and which need a small checked list, and says so in the spec |
