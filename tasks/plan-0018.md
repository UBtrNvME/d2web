# Plan: element kinds and the layered inspector (spec 0018, slice 1)

Status: accepted 4 November 2026 (ADR 0015, spec 0018, slice 1 first). Task list: [todo-0018.md](todo-0018.md).

## Overview
Replace the generated field list with a registry of element kinds. Slice 1: Element, Node and Edge sections, Shape and Text kinds (Markdown, Code with a language switch, LaTeX), a Type picker between Shape and Text, an edge panel, removal of the old lists. Tables, classes, images, diagrams and gestures are later slices.

## Dependency graph
```
1 probe: block strings and conversions via client.edit
  └─ 2 registry + canonical state + Shape/Text descriptors (pure, Node-tested)
       ├─ 3 section renderer + control vocabulary; Element/Node/Shape sections   (first visible slice)
       │    ├─ 5 Text surface: textarea, Md/Code/LaTeX switch, commit keys
       │    │    └─ 6 code language switch (list exported from D2)
       │    └─ 7 edge panel
       └─ 4 conversion + Type picker (Shape <-> Text) with loss sheet
8 remove old inspector lists; docs and handoff
```

## Decisions
- Registry, descriptors and conversion are pure TypeScript in `packages/d2editor/src`, tested in Node like `traits.ts`; the DOM renderer is thin.
- Old controls stay until the generated section replaces each, so no task leaves the editor broken.
- No change to `packages/d2web` or the worker protocol unless task 1 shows a block string cannot be written; then stop and ask.

## Risks
| Risk | Impact | Mitigation |
| --- | --- | --- |
| LaTeX or md block cannot be written with `set` | Text kind blocked | Task 1 first; ask before adding an op |
| Shape to Text loses a label's meaning (label becomes block text) | Surprising edit | Conversion rule tested against D2; undo; loss sheet only for real loss |
| D2's highlighter language list is large | Heavy menu | Common list plus search; export at build |
| Detection misreads an unusual object | Wrong panel | Fallback "edit in source"; corpus test |

## Parallelism
Tasks 5 and 7 are independent after 3. Everything else is sequential.
