# Tasks: spec 0017 capabilities

Plan: [plan-0017.md](plan-0017.md). ADR 0014 and spec 0017 accepted 4 November 2026. Each task leaves `mise run check` green.

## Phase 1: Source of truth

- [x] **1. Export D2's keyword table (M).** The Go build writes a JSON table of style, shape and connection keywords with value domains (enum, range, colour, boolean, text) and the painter's drawn/not-drawn flag.
  - Acceptance: JSON lists every keyword in `d2ast` reserved keywords and `d2target` shapes at the pinned commit; each entry has a domain; entries D2 validates only in code are marked and listed in the spec.
  - Verify: new Node test compares the JSON with `imports/d2`; `mise run check`.
  - Depends on: none. Files: `packages/d2web-wasm/keywords/{keywords,keywords_test}.go`, `packages/d2editor/src/keywords.json` (checked in; `UPDATE=1 go test ./keywords` rewrites it).
  - Done 4 November 2026. Deviations: the test is Go (it runs under `test:wasm`), not Node, because the probes call D2's compiler; the editor imports the checked-in JSON, so `build.mjs` is unchanged. Names and enums come from `d2ast`/`d2target`; style number ranges and booleans are validated only in `d2graph` code, so they are written in `keywords.go` and each is probed against D2 at its edges (a widened opacity range fails the test). Non-style numbers (`width`, `top`, grid) carry a minimum that D2 does not validate here. The "drawn / not drawn" flag is not in the table: it needs the painter audit, moved to task 3.
- [ ] **2. `capabilities()` for shapes (M).** Pure function: fields with value, source, availability; actions from edit ops.
  - Acceptance: for shape, container, `image`, `sql_table`, code block: every advertised field changes a real compile when set; unavailable ones carry D2's reason.
  - Verify: `mise exec -- node --test packages/d2editor/tests/capabilities.test.mjs`.
  - Depends on: 1. Files: `src/capabilities.ts`, the test.
